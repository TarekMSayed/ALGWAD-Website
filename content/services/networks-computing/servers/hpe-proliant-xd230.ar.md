هل تبحث عن حل مرن وقابل للتوسع الأفقي لأعباء عمل الحوسبة عالية الأداء (HPC) لديك؟ سيرفر HPE ProLiant Compute XD230 هو منصة حوسبة عالية الأداء متطورة مصممة لتقديم أداء استثنائي ومرونة في تطبيقات HPC التقليدية. متوفر بهيكل مدمج بحجم 1U، ويدعم أحدث معالجات Intel® Xeon® 6، ويتميز بمعمارية قابلة للتوسع مُحسّنة لأعباء عمل HPC عالية الكثافة. تحسّن كبير في النطاق الترددي يعزز الأداء، بينما تضمن إدارة HPE iLO أمانًا موثوقًا. تتضمن المنصة أيضًا خيارات إطار عمل متقدمة مثل HPE Slingshot، إلى جانب مدير المجموعات عبر HPE Performance Cluster Manager (HPCM)، مما يقرّب قدرات الحوسبة الفائقة إلى نطاقات أصغر. كما توفر خيارات تبريد تدعم كلًا من التبريد بالهواء (CLC) والتبريد السائل المباشر.

## المواصفات الفنية

| المواصفة       | القيمة |
|---            |---|
| أعباء العمل الرئيسية | الصناعة (CAE، EDA)، الطقس والمناخ، القطاع المالي (FSI) |
| الشكل الخارجي  | 1U رف |
| التبريد        | تبريد بالهواء (عبر تبريد سائل بحلقة مغلقة)، تبريد سائل مباشر |
| المعالج        | 2P معالج Intel Xeon 6900 |
| كرت الرسومات (GPU) | غير متاح |
| أقصى ذاكرة     | تصل إلى 3 تيرابايت DDR5 |
| التخزين        | أقراص SFF، EDSFF |
| الإدارة        | HPE iLO، HPE Compute Ops Management، HPE Performance Cluster Manager |
