هل تحتاج إلى سيرفر بمعالجين يتوسع لتحليلات البيانات وأحمال عمل السحابة الهجينة؟ سيرفر HPE ProLiant DL380 Gen11 هو منصة متعددة الاستخدامات بحجم 2U وبمعالجين (2P)، مصممة للتعامل مع التطبيقات المتطلبة بقدرة معالجة قوية، وكثافة ذاكرة عالية، وحركة بيانات سريعة. مدعوم بمعالجات Intel® Xeon® Scalable من الجيلين الرابع والخامس بحتى 64 نواة، وذاكرة تصل إلى 8 تيرابايت، و20 محرك أقراص EDSFF، ومنافذ PCIe Gen5، فهو مثالي لأنظمة التخزين المعرّف بالبرمجيات، وتحويل ترميز الفيديو، والبيئات الافتراضية. مصمم لتقنية المعلومات الحديثة، يقدم DL380 Gen11 تجربة تشغيل سحابية، وأماناً مدمجاً، وأداءً محسّناً لدفع أعمالك إلى الأمام.

## المواصفات الفنية

| المواصفة | القيمة |
|---|---|
| أحمال العمل الرئيسية | VDI، الافتراضية، الحاويات، إدارة البيانات |
| شكل الهيكل | رف بحجم 2U |
| التبريد | تبريد هوائي، تبريد سائل مباشر |
| المعالج | معالجين (2P) من الجيل الرابع أو الخامس Intel Xeon Scalable |
| وحدة معالجة الرسوميات | حتى 3 وحدات عريضة مزدوجة أو 4 وحدات أحادية |
| أقصى ذاكرة | حتى 8 تيرابايت DDR5 |
| التخزين | LFF، SFF، محركات EDSFF |
| الإدارة | HPE iLO 6، HPE Compute Ops Management |
