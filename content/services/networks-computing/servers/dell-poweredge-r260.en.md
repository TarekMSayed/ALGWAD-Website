The Dell PowerEdge R260 is a 1U, single-socket short-depth server designed to address entry-level compute demands of Near-Edge, Remote Office / Branch Office (ROBO) and SMB.

## Technical specifications

| Spec          | Value |
|---            |---|
| Top workloads | SMB, near-edge, remote office |
| Form factor   | 1U |
| Processor     | 1 x Intel® Xeon® 6 6300 series processor |
| Max memory    | 4 x 32 GB DDR5 (128 GB) |
| Max storage   | 46 TB |
| GPU           | N/A |
