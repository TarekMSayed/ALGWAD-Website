The HPE ProLiant DL365 Gen11 is a rack-optimized, 1U dual-socket server engineered for dense, high-performance computing. Delivering enhanced throughput and expanded memory capacity, it supports 4th and 5th Generation AMD EPYC™ processors with up to 160 cores, enabling robust 2P compute capability. With increased memory bandwidth, PCIe Gen5 I/O, EDSFF storage options, and GPU support, the DL365 Gen11 is ideal for virtualization, high-density databases, AI inference, and other data- and compute-intensive workloads.

## Technical specifications

| Spec          | Value |
|---            |---|
| Top workloads | Data, Container, Hybrid Cloud, VDI, Virtualization |
| Form factor   | 1U rack |

| Processor     | 2P 4th or 5th Generation AMD EPYC |
| GPU           | 2 Double-Wide or 2 Single-Wide |

| Storage       | EDSFF, SFF drives |
| Management    | HPE iLO 6, HPE Compute Ops Management |
