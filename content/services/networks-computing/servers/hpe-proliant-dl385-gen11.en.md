Need an accelerator-optimized solution for AI or Big Data workloads? The HPE ProLiant DL385 Gen11 is a 2U, dual-processor server powered by 4th & 5th Gen AMD EPYC™ processors with up to 160 cores, enhanced memory bandwidth and capacity, PCIe Gen5 I/O, advanced GPU support, and EDSFF storage. It delivers exceptional compute performance, high-speed data transfer, and deep memory for demanding applications. Security is built-in with HPE Silicon Root of Trust and AMD Infinity Guard.

## Technical specifications

| Spec          | Value |
|---            |---|
| Top workloads | VDI, Virtualization |
| Form factor   | 2U rack |
| Cooling       | Air, Direct Liquid Cooled |
| Processor     | 2P 4th or 5th Generation AMD EPYC |
| GPU           | 4 Double-Wide or 8 Single-Wide |
| Max memory    | Up to 6TB DDR5 |
| Storage       | EDSFF, SFF, LFF drives |
| Management    | HPE iLO 6, HPE Compute Ops Management |
