The HPE ProLiant Compute DL360 Gen12 is a compact 1U 2P server that delivers strong compute performance, scalable memory density, and high-speed data transfer to support demanding applications. Powered by Intel® Xeon® 6 processors with up to 144 cores, up to 8 TB of memory, and support for up to 20 EDSFF E3.S NVMe drives, the DL360 Gen12 is well suited for enterprise and hybrid cloud environments. The server also offers flexible front-storage options, supporting SFF and E3.S drives, an OS boot device, and optional front OCP NICs for added scalability. Engineered for the future, the HPE ProLiant Compute DL360 Gen12 features next-level security, optimized performance and efficiency, and automated, AI-driven management to help improve IT productivity.
