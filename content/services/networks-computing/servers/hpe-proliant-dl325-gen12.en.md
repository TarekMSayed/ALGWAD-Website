The HPE ProLiant Compute DL325 Gen12 optimizes server performance and efficiency in environments with limited power and space. Equipped with up to 5th Gen AMD EPYC™ processors (up to 192 cores), expanded memory capacity (up to 6 TB), and the updated HPE iLO 7 management, it delivers enhanced compute performance, larger memory footprints for demanding workloads, and improved datacenter efficiency and manageability compared with previous generations.

## Technical specifications

| Spec          | Value |
|---            |---|
| Top workloads | Hybrid Cloud, Container, and Virtualization |
| Form factor   | 1U rack |
| Cooling       | Air, Closed-Loop Liquid Cooled, Direct Liquid Cooled |
| Processor     | 1P 5th Generation AMD EPYC™ |
| GPU           | 2 Double-Wide or 4 Single-Wide |
| Max memory    | Up to 6TB DDR5 |
| Storage       | LFF, SFF, EDSFF drives |
| Management    | HPE iLO 7, HPE Compute Ops Management |
