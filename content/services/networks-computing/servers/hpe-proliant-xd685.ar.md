سيرفر HPE ProLiant Compute XD685 مدعوم باختيارك ما بين كروت شاشة ™NVIDIA أو AMD Instinct، ومعالجات AMD EPYC من فئة 9005، ما يجعله مثاليًا لتدريب نماذج الذكاء الاصطناعي واسعة النطاق، ومعالجة اللغة الطبيعية، والتدريب متعدد الوسائط (Multimodal).

## المواصفات الفنية

| المواصفة       | القيمة |
|---            |---|
| أفضل أحمال العمل | تدريب وضبط نماذج الذكاء الاصطناعي واسعة النطاق |
| الشكل          | 5U بتبريد سائل مباشر، أو 6U بتبريد هوائي |
| التبريد        | تبريد هوائي أو تبريد سائل مباشر |
| المعالج        | معالجان (2P) من الجيل الخامس ™AMD EPYC |
| كرت الشاشة (GPU) | 8 كروت NVIDIA H200 SXM أو 8 كروت NVIDIA Blackwell (B200) |
| أقصى ذاكرة     | حتى 6 تيرابايت DDR5 |
| التخزين        | أقراص EDSFF |
| الإدارة        | HPE iLO 6، HPE Performance Cluster Manager |
