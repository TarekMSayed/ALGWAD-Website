The PowerEdge R360 is a 1U, single-socket server designed to address evolving compute demands for SMBs, Remote Office / Branch Office (ROBO) and Near-Edge.

## Technical specifications

| Spec          | Value |
|---            |---|
| Top workloads | SMB, near-edge, remote office |
| Form factor   | 1U |
| Processor     | 1 x Intel® Xeon® 6 6300 series processor |
| Max memory    | 4 x 32 GB DDR5 (128 GB) |
| Max storage   | 64 TB |
| GPU           | 1 x 60W (SW) |
