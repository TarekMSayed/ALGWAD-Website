Need a compute-dense server built for hybrid cloud and modern, containerized workloads? The HPE ProLiant DL360 Gen11 is a rack-optimized 1U 2P platform delivering strong compute performance, high-speed data movement, and deep memory scalability in a compact footprint. Powered by 4th and 5th Gen Intel® Xeon® Scalable processors with up to 64 cores, up to 8 TB of memory, 20 EDSFF drives, and PCIe Gen5 I/O, it's well suited for EDA, CAD, VDI, and other data-intensive workloads. Designed to streamline IT operations, the DL360 Gen11 combines enterprise security with a cloud operating experience and optimized performance to help move your business forward.

## Technical specifications

| Spec | Value |
|---|---|
| Top workloads | Container, Hybrid Cloud, VDI, Virtualization |
| Form factor | 1U rack |
| Cooling | Air-Cooled, Closed Loop Liquid Cooling, Direct Liquid Cooling (DLC) |
| Processor | 2P 4th or 5th Gen Intel Xeon Scalable Processors |
| GPU | Up to 3 Single-Wide NVIDIA L4 GPUs |
| Max memory | Up to 8TB DDR5 |
| Storage | LFF, SFF, EDSFF drives |
| Management | HPE iLO 6, HPE Compute Ops Management |
