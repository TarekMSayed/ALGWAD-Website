The HPE ProLiant DL325 Gen11 is a cost-effective 1U, single-socket server that balances compute, memory, and network bandwidth for efficient 1P economics. It supports 4th and 5th-Generation AMD EPYC™ 9004/9005 Series processors with up to 160 cores, expanded memory capacity (up to 3 TB), high-speed PCIe Gen5 I/O, and EDSFF storage. With support for up to two front GPUs, it delivers strong performance for virtualized environments. Silicon Root of Trust anchors server firmware to the AMD Secure Processor fingerprint, enhancing boot-time security. Ideal for software-defined compute, CDN, VDI, and secure edge applications that require balanced processor, memory, and network throughput.
