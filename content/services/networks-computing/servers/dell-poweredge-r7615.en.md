The PowerEdge R7615 is ready for software-designed workloads with up to two 4th generation AMD EPYC™ processors, up to 8x PCIe Gen5 slots and DDR5 memory.

## Technical specifications

| Spec          | Value |
|---            |---|
| Top workloads | Software defined storage (SDS), virtualisation, and data analytics |
| Form factor   | 2U |
| Processor     | 1 x AMD EPYC™ 9004 processor |
| Max memory    | 12 x 256 GB DDR5 (3 TB) |
| Max storage   | 430 TB |
| GPU           | 6 x 75W (SW); 3 x 300W (DW) |
