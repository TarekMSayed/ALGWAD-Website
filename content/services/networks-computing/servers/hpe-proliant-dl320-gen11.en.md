Need to run edge AI workloads, like computer vision with GPU acceleration, or support distributed data solutions with expandable storage? The HPE ProLiant DL320 Gen11 is a 1U, 1P server with a compact, modular, workload‑driven design built for edge computing. It delivers strong performance at 1P economics and is an excellent fit for virtualized and containerized workloads, making it ideal for demanding edge environments.

## Technical specifications

| Spec          | Value |
|---            |---|
| Top workloads | Container, Hybrid cloud, VDI, Virtualization |
| Form factor   | 1U rack |
| Cooling       | Air cooled |
| Processor     | 1P 4th or 5th Gen Intel Xeon Scalable |
| GPU           | 2 Double-wide or 4 Single-wide |
| Max memory    | Up to 2TB DDR5 |
| Storage       | SFF, LFF, EDSFF drives |
| Management    | HPE iLO 6, HPE Compute Ops Management |
