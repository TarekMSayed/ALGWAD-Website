Looking for a capable laptop with a larger workspace? The New XPS 16 Laptop is powered by a Series 3 Intel® Core™ Ultra 7 Processor 355, running Windows 11 Home. It comes equipped with Intel® Graphics, 16 GB of LPDDR5X memory, and 1 TB of SSD storage, paired with a 16" Non-Touch 2K (1920x1200) display.

## Technical specifications

| Spec             | Value |
|---               |---|
| Processor        | Series 3 Intel® Core™ Ultra 7 Processor 355 |
| Operating System | Windows 11 Home |
| Graphics Card    | Intel® Graphics |
| Memory           | 16 GB LPDDR5X |
| Storage          | 1 TB SSD |
| Display          | 16" Non-Touch 2K (1920x1200) |
