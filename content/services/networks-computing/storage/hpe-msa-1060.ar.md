حزمة مصفوفة التخزين HPE MSA 1060 ذات الحجم الصغير (SFF) وبارتفاع 2U، مزودة بوحدتي تحكم منفذين منفصلين بقناة ألياف (Fibre Channel) بسرعة 16 جيجابايت، و12 محرك أقراص صلبة HDD بحجم SFF وسعة 1.2 تيرابايت بسرعة 10K، و4 أجهزة إرسال واستقبال SFP+ بقناة ألياف بسرعة 16 جيجابايت، بالإضافة إلى وحدة تزويد طاقة متكررة (Redundant Power Supplies) بقدرة 580 واط.

## المواصفات الفنية

| الخاصية | القيمة |
|--- |---|
| وصف المحركات | يتضمن 12 محرك أقراص صلبة HDD بحجم SFF وسعة 1.2 تيرابايت وسرعة 10K. إمكانية إضافة حتى 12 محرك إضافي من نوع HDD و/أو SSD لكل مصفوفة أساسية |
| عامل الشكل | رف 2U (2U rack) |
| السعة | تصل إلى 383 تيرابايت (المصفوفة الأساسية) وتصل إلى 2.6 بيتابايت مع التوسعة القصوى |
| وحدة تحكم التخزين | وحدتان من نوع 16 Gb Fibre Channel 2-port Controllers |
| أنظمة التشغيل المتوافقة | Windows Server® 2022; Windows Server® 2019; Windows Server® 2016; VMWare vSphere™ 6.7; Red Hat® Linux 8; SUSE™ SLES 15؛ راجع HPE SPOCK لمزيد من التفاصيل. |
