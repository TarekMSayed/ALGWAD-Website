This HPE Storage MSL 3040 Tape Library includes one LTO-9 SAS Drive and 20 LTO-9 (45 TB) data cartridges along with cartridge labels. Out of the box this library can back up 900 TB of compressed data with a total capacity of 12.6 PB when fully configured.

## Technical specifications

| Spec          | Value |
|---            |---|
| Drive type | LTO-9 Ultrium 45000 SAS |
| Capacity   | 900 TB maximum out of the box (compressed 2.5:1) |
| Host interface | 12 GB/s SAS (LTO-9) |
| Transfer rate | 300 MB/s |
| Number of cartridge slots | 40 slots for the base module |
| Form factor | 3U per module to a maximum of 48U |
| Encryption capability | AES 256-bit |
