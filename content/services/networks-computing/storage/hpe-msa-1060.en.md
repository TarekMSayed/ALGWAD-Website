HPE MSA 1060 2U small form factor storage array bundle with two 16 Gb Fibre Channel 2-port controllers, twelve 1.2 TB 10K SFF Hard Disk Drives, four 16 Gb Fibre Channel SFP+ transceivers, and two 580W redundant power supplies.

| Capacity       | Up to 383 TB (base array), up to 2.6 PB with maximum expansion |
| Storage controller     | 2x 16 Gb Fibre Channel 2-port Controllers |
| Compatible operating systems           | Windows Server® 2022; Windows Server® 2019; Windows Server® 2016; VMWare vSphere™ 6.7; Red Hat® Linux 8; SUSE™ SLES 15; See HPE SPOCK for more details. |
