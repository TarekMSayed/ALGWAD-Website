The HPE Aruba Networking CX 6200 Switch Series delivers enterprise-class access switching with flexible stacking, versatile uplink options, and intelligent monitoring, built for simple deployment and centralized management across wired, wireless, and WAN environments.

## Technical specifications

| Spec                    | Value |
|---                      |---|
| Connectivity & routing  | Enterprise-class connectivity with support for ACLs, robust QoS and common protocols such as static and OSPF routing |
| Scalability             | 8-member switch VSF stacking for up to 384 downlink ports |
| Modular uplinks         | Versatile 1G/10G uplinks with LRM and MACsec 256 support on modular switches |
| Fixed power uplinks     | Convenient built-in 1G/10G uplinks on fixed power switches, plus additional cost-efficient 1G uplink switch models |
| PoE                     | Industry standard Power over Ethernet with up to 30W PoE (Class 4) per port on fixed power switches and up to 60W PoE (Class 6) per port on modular power switches |
| Monitoring              | Intelligent monitoring, visibility, and troubleshooting with Network Analytics Engine |
| Management              | Single pane of glass management via HPE Aruba Central across wired, wireless, and WAN |
| Deployment              | Simple, one-touch deployment with the CX Mobile App |
| Automation              | Automated configuration and verification with HPE Aruba Networking CX Multi-Edit software |
| Security                | Secure and simple access for users and IoT with Dynamic Segmentation |
| Visibility              | Deep visibility and application recognition with CX Edge Insights, including granular data point collection with search, sort and reporting |
