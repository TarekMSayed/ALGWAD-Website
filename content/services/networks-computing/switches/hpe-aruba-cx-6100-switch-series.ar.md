توفر سلسلة سويتشات HPE Aruba Networking CX 6100 اتصالية من الطبقة الثانية (Layer 2) على مستوى المؤسسات بأداء غير محجوب، مع مرونة في التكديس، ودعم PoE مدمج، وجاهزية للبرمجيات المعرّفة، وهي مصممة لتوفير نشر بسيط وإدارة مركزية عبر بيئات الشبكات السلكية واللاسلكية وشبكات WAN.

## المواصفات الفنية

| الخاصية                 | القيمة |
|---                      |---|
| الأداء                  | أداء غير محجوب (Non-blocking) |
| الاتصالية والتوجيه      | اتصالية على مستوى المؤسسات من الطبقة الثانية (Layer 2) مع دعم قوائم التحكم بالوصول (ACLs)، وجودة خدمة (QoS) قوية، والتوجيه الثابت |
| الوصلات الصاعدة وPoE    | وصلات صاعدة مدمجة 1/10GbE، ودعم حتى 740 وات من تغذية PoE (Class 4) لدعم أجهزة إنترنت الأشياء (IoT) |
| التكديس                 | دعم حتى 6 سويتشات (أو أعضاء) في تكديس واحد عبر طوبولوجيا السلسلة أو الحلقة |
| الموديل المدمج          | موديل مدمج بـ12 منفذ وبدون مروحة تبريد لنشر هادئ |
| الإدارة                 | إدارة موحدة من واجهة واحدة عبر HPE Aruba Networking Central للشبكات السلكية واللاسلكية وWAN |
| الأتمتة                 | تهيئة وتحقق آلي عبر HPE Aruba Networking Multi-Edit |
| البرمجيات المعرّفة       | جاهزية للبرمجيات المعرّفة عبر واجهات REST API |
| مرونة المنافذ           | تبسيط عمليات الإضافة والنقل والتغيير عبر المنافذ عديمة اللون (Colorless Ports) |
| قابلية التوسع           | تكديس VSF لحتى 6 أعضاء |
