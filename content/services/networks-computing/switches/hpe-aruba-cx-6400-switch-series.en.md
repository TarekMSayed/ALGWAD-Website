The HPE Aruba Networking CX 6400 Switch Series delivers powerful, modular Layer 3 switching with advanced routing, high-availability, and security features, built to power the modern network core and aggregation layer.

## Technical specifications

| Spec                    | Value |
|---                      |---|
| Switching architecture  | Powerful, modular Layer 3 switches with BGP, MPLS, EVPN, VXLAN, VRF, and OSPF with robust security and QoS |
| Performance             | High performance switching with up to 28 Tbps with 11.4 Bpps |
| High availability       | Industry-leading VSX redundancy with redundant power supplies and fans |
| Port density            | Full density HPE Smart Rate (1/2.5/5GbE) multi-gigabit, 60W PoE and SFP+ modules |
| Port speeds             | High speed, non-blocking 1GbE, 10GbE, 25GbE, 40GbE, 50GbE, and 100GbE ports (50GbE requires 50G DACs for interconnect and VSX; transceiver support enabled by a future software release) |
| Monitoring              | Intelligent monitoring, visibility, and remediation with Network Analytics Engine |
| Management              | HPE Aruba Networking Central or HPE Mist |
| Automation              | Multi-Edit support for automated configuration and verification |
| Security                | Dynamic segmentation enables secure and simple access for users and IoT devices |
