The HPE Aruba Networking CX 6300 Switch Series delivers stackable Layer 3 access switching with advanced routing, high-performance multi-gigabit connectivity, and intelligent monitoring, built for flexible and resilient campus and data center access deployments.

## Technical specifications

| Spec                    | Value |
|---                      |---|
| Switching architecture  | Stackable Layer 3 switches with BGP, EVPN, VXLAN, VRF, and OSPF with robust security and QoS |
| Performance             | High performance 880 Gbps system switching capacity, 660 MPPS of system throughput and up to 200 Gbps stacking bandwidth (400 Gbps at full duplex) |
| Form factor & PoE       | Compact 1U switches with full density HPE Smart Rate (1G/2.5G/5G/10GbE) multi-gigabit, up to 90W PoE (Class 8) and 10G LRM SFP+ available on select models |
| Data center deployment  | Power-to-port switch bundle with back-to-front airflow ideal for data center 1GbE ToR and OOBM deployments |
| CX 6300L access switches | Three stackable, high-performance Layer 2-only CX 6300L access switches with HPE Smart Rate Multi-Gigabit and MACsec encryption (S0E91A) |
| Uplinks                 | Built-in high speed 1/10/25/50GbE uplinks, with 50GbE connectivity via 50GbE DACs |
| Monitoring              | Intelligent monitoring, visibility, and remediation with Network Analytics Engine |
| Management              | HPE Aruba Networking Central or HPE Mist |
| Automation              | Multi-Edit support for automated configuration and verification |
| Security                | Dynamic Segmentation enables secure and simple access for users and IoT |
| High availability       | Choice between 2 to 10-member Virtual Switching Framework (VSF) stacking and 2-member Virtual Switching Extension (VSX) cluster, with VSX Live Upgrades and VSF in-service software upgrades for ISSU orchestration with no downtime |
