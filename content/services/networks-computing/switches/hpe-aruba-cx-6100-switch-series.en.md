The HPE Aruba Networking CX 6100 Switch Series delivers non-blocking, enterprise-class Layer 2 connectivity with flexible stacking, built-in PoE, and software-defined readiness, built for simple deployment and centralized management across wired, wireless, and WAN environments.

## Technical specifications

| Spec                    | Value |
|---                      |---|
| Performance             | Non-blocking performance |
| Connectivity & routing  | Enterprise-class Layer 2 connectivity with support for ACLs, robust QoS and static routing |
| Uplinks & PoE           | Convenient built-in 1/10GbE uplinks and up to 740W of Class 4 PoE for support of IoT devices |
| Stacking                | Support for up to 6 switches (or members) in a stack via chain or ring topology |
| Compact model           | Compact and fanless 12 port model for quiet deployment |
| Management              | Single pane of glass management via HPE Aruba Networking Central across wired, wireless, and WAN |
| Automation               | Automated configuration and verification with HPE Aruba Networking Multi-Edit |
| Software-defined        | Software defined ready with REST APIs |
| Port flexibility        | Simplify adds, moves and changes with colorless ports |
| Scalability              | 6-member switch VSF stacking |
