توفر سلسلة سويتشات HPE Aruba Networking CX 6200 اتصالية وصول على مستوى المؤسسات، مع مرونة في التكديس، وخيارات وصلات صاعدة متنوعة، ومراقبة ذكية، وهي مصممة لتوفير نشر بسيط وإدارة مركزية عبر بيئات الشبكات السلكية واللاسلكية وشبكات WAN.

## المواصفات الفنية

| الخاصية                 | القيمة |
|---                      |---|
| الاتصالية والتوجيه      | اتصالية على مستوى المؤسسات مع دعم قوائم التحكم بالوصول (ACLs)، وجودة خدمة (QoS) قوية، وبروتوكولات شائعة مثل التوجيه الثابت وتوجيه OSPF |
| قابلية التوسع           | تكديس VSF لحتى 8 سويتشات لدعم ما يصل إلى 384 منفذ تنازلي |
| الوصلات الصاعدة المعيارية | وصلات صاعدة متعددة الاستخدامات 1G/10G مع دعم LRM وMACsec 256 على السويتشات المعيارية |
| الوصلات الصاعدة الثابتة  | وصلات صاعدة مدمجة 1G/10G على سويتشات الطاقة الثابتة، بالإضافة إلى موديلات سويتشات 1G فعّالة من حيث التكلفة |
| تغذية عبر الإيثرنت (PoE) | دعم قياسي لتقنية Power over Ethernet بحتى 30 وات (Class 4) لكل منفذ على سويتشات الطاقة الثابتة، وحتى 60 وات (Class 6) لكل منفذ على سويتشات الطاقة المعيارية |
| المراقبة                | مراقبة ذكية ورؤية واضحة واستكشاف أخطاء عبر محرك Network Analytics Engine |
| الإدارة                 | إدارة موحدة من واجهة واحدة عبر HPE Aruba Central للشبكات السلكية واللاسلكية وWAN |
| النشر                   | نشر بسيط بلمسة واحدة عبر تطبيق CX Mobile App |
| الأتمتة                 | تهيئة وتحقق آلي عبر برنامج HPE Aruba Networking CX Multi-Edit |
| الأمان                  | وصول آمن وبسيط للمستخدمين وأجهزة إنترنت الأشياء (IoT) عبر Dynamic Segmentation |
| الرؤية                  | رؤية عميقة والتعرف على التطبيقات عبر CX Edge Insights، مع جمع بيانات دقيق يشمل البحث والفرز وإعداد التقارير |
