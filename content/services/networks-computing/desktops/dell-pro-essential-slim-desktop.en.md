Looking for a business-ready slim desktop with manageability built in? The Dell Pro Essential Slim Desktop is powered by an Intel® Core™ i5 14500 vPro® processor with 14 cores, running Windows 11 Pro. It features Intel® UHD Graphics 730, 16GB of DDR5 memory, and a 512GB PCIe SSD, delivering solid performance in a space-saving design.
